# How the ICE spending comparison was made

**Release status: draft.** This public-safe version accompanies [the September 27, 2026 article](https://www.kevinmcnellis.com/posts/ICE_IGSA/). Its source links and release inventory still need a fresh-clone check. File paths written as plain text below identify saved analytical results; they are not public download links until the release inventory includes them. The [claim-audit record](audit/claim_audit.json) retains unresolved findings and author-accepted wording; this methodology does not certify every claim in the published article.

The analysis compares two layers of federal spending records. USAspending.gov **File B** reports account activity by program activity and object class without identifying a recipient. **File C** reports transactions associated with awards, plus *Unlinked* rows that may have an amount but no usable public award or recipient link. The reported difference between the two totals is an accounting comparison. It does not identify payments under intergovernmental service agreements (IGSAs), missing awards, or the cost of detention at a particular facility. [USAspending’s data-source guide](https://www.usaspending.gov/data/data-sources-download.pdf) explains the reporting layers.

## Accounts, period, and original files

The main comparison selects ICE Operations and Support (`070-0540`) and Procurement, Construction, and Improvements (`070-0545`). It uses the reported object class `25.4`, *operation and maintenance of facilities*. [OMB Circular A-11, section 83](https://www.whitehouse.gov/wp-content/uploads/2025/08/s83.pdf#page=16) defines the class; it can cover facilities unrelated to detention and is not an IGSA identifier.

The reporting window is **FY2025 P05–P12 plus FY2026 P02–P10**, described for readers as February 2025 through July 2026. It selects when records were reported, not necessarily when every underlying commitment was first made. FY2026 P02 includes October 2025 activity under the [Treasury reporting schedule](https://tfx.treasury.gov/system/files/2025-09/fy26-dabs-reporting-window-schedule.xlsx).

## How the obligation totals were calculated

An **obligation** is a reported commitment to spend federal funds, not necessarily a cash payment. File B values are cumulative within a fiscal year. At each checkpoint, the calculation adds `obligations_incurred` and the already-signed `deobligations_or_recoveries_or_refunds_from_prior_year`, then uses:

> **File B net obligations = net(FY2025 P12) − net(FY2025 P04) + net(FY2026 P10)**.

Subtracting P04 removes October 2024 through January 2025 from the FY2025 cumulative amount. FY2026 starts a new fiscal year, so P10 is added once. The calculation does not add successive cumulative checkpoints.

File C adds signed `transaction_obligated_amount` in the selected reporting periods after applying the same account and `25.4` filters. In these frozen files, the selected `25.4` rows come from Contracts and Unlinked members; no Assistance row meets the selection. Positive entries increase the total; negative adjustments reduce it. Blank amounts remain unreported and are excluded from the numeric sum, rather than being recoded as reported zeroes. No File B row is linked to a particular File C award by this subtraction. Treasury’s [Governmentwide Spending Data Model](https://tfx.treasury.gov/data-transparency/gsdm) supplies the reporting-field definitions used to interpret the extracts.

Across the two ICE accounts, the frozen calculation gives **$5,907,357,331.34** in File B, **$3,136,530,747.79** in File C, and a **$2,770,826,583.55** difference. Five numeric Unlinked File C rows contribute **$9,498,809.00** to the File C total without named recipients. The exact [Chart 1 output receipt](outputs/chart_1/verification.json) has SHA-256 `9c0bacc3c12fc6e31bc36ec3ddc0e9bed60c2c20c98e60512e103f18d91ba0cb`. These amounts do not reconcile every transaction between the two reporting layers.

## Award-description screen

A separate, reviewed screen searches `prime_award_base_transaction_description` in **54,202 File C rows** for the two selected ICE accounts across all object classes and reporting periods in the two frozen File C downloads. It searches names and approved phrases for the **271** roster entities observed during the wider January 21, 2025–July 9, 2026 period. A name match is a candidate relationship, not a payment allocation. The screen’s `IGSA` group comprises the **224** entities with any `IGSA`, `DIGSA`, or `USMS IGA` label during that wider period. Its federal/contract group comprises **49** with any `BOP`, `SPC`, `CDF`, `STAGING`, `DOD`, `USMS CDF`, or `MOC` label. Five facilities appear in both groups because types can change.

The checked result finds **21 of 49** federal/contract-group facilities on **76 distinct awards** with **$2,229,581,023.16** in selected `25.4` File C obligations, and **five of 224** IGSA-group facilities on **12 distinct awards** with **$96,196,138.33**. Only two awards name a facility whose every observed type is in the IGSA group: direct CoreCivic orders for Torrance and Cibola totaling **$17,465,361.06** in selected `25.4` obligations. Amounts are summed by distinct award within each group, not by facility–award pair; overlapping groups and multi-facility awards are not additive. Types were observed at some point in the study window and were **not** assigned to each award’s transaction date. Descriptions may omit a facility, and Unlinked records in these frozen extracts have blank descriptions. The release [screen statistics receipt](outputs/facility_name_screen/statistics_check.json) has SHA-256 `f28e3525a4d1b4158b3b2f0a69cc2d75a1fae516bbb19cd0bf3ae0bd1a3764c1`. ## Torrance, Cibola, and the limits of the search

The expanded Torrance/Cibola check scanned **1,815,637 rows returned in the two frozen DHS File C downloads**. The `070` prefix identifies DHS; the account-download request selected all federal accounts for that agency code. The check reported zero matches for the specified county agreement numbers, referenced IGSA task-order numbers, and county UEIs in the fields it searched. Its 33 county-geography leads comprise **21 Assistance rows** and **12 rows for the two direct CoreCivic orders**. Geography alone does not identify an agreement payment. The direct orders are positive controls showing that the search can find known contract records; a zero identifier result in these two download vintages is not proof that a county payment is absent from every federal or local record system. The canonical check receipt, `provenance/torrance_cibola_file_c_verification.json` (SHA-256 `ae198ebcf64961d5e0a2ae6f1e82e1f0399bcb4a03b398994c03379705c4debb`), is **not bundled**; the [bundled claim-audit record](audit/claim_audit.md) gives the checked scope and result.

## The separate four-class chart

The supplemental chart uses **Operations and Support (`070-0540`) only**. Its four bars cover object classes `25.4`, `31.0`, `21.0`, and `25.2`. Their File B-minus-File C differences sum to **$4,799,482,587.89**, displayed as $4.8 billion. The construction account (`070-0545`) appears only in a separate note; it is not part of the four bars or headline.

The four File C totals include **$58,987,437.93** of numeric Unlinked rows with blank `award_unique_key`. Those rows are in File C, but their award linkage is unresolved. “Not tied to any award” is therefore too strong as a description of the whole difference. The chart owner’s final technical build passed its source and rendering checks but retains an **interpretation warning**. A [dated live-asset check](audit/live_asset_verification.json) found that the article’s gap-chart URL returned the exact selected PNG on September 28, 2026; publication does not resolve that warning. [CBS News](https://www.cbsnews.com/news/ice-spending-detention-capacity-gao-report/) reports an escrow advance and later facility purchases; it does **not** identify the chart’s roughly $5.0 billion File B-minus-C construction-class difference as the money used for those purchases. The local final-build receipt is `outputs/gap_chart_draft/verification.json`, SHA-256 `24423d748c4fd40e37e679f31e198e3f1e4a39c59b71fb8ea79e829d502e553d`.
